Premium authentication lets players who own an official Minecraft account from Mojang or Microsoft join your server without ever typing a password. rLogin silently verifies their identity in the background by checking with Mojang's session servers, so the login experience is completely invisible — they connect and they're in.

## What Is a Premium Player?

A premium player is someone who purchased Minecraft through the official Mojang or Microsoft store and logs in with a valid Microsoft account. Their game client automatically proves their identity to any server that requests verification. Because Mojang acts as the trusted authority, no password is needed on the server side.

## How Premium Authentication Works

When a premium player connects to your server, rLogin runs through the following steps automatically:

<Steps>
  <Step title="Player connects">
    A player with an official Minecraft account joins your server. Their client sends an authenticated session token generated by the Minecraft launcher.
  </Step>
  <Step title="rLogin queries Mojang">
    rLogin calls Mojang's `HasJoined` session API endpoint at `sessionserver.mojang.com`, passing the player's username and session data to verify the claim.
  </Step>
  <Step title="Session is validated">
    Mojang responds confirming that the player's session is authentic and the username belongs to their account.
  </Step>
  <Step title="Player is logged in automatically">
    rLogin marks the player as authenticated. No password prompt appears, and no extra steps are required from the player.
  </Step>
</Steps>

## Configuration Requirements

For premium authentication to work, your server's `auth-mode` must be set to either `auto` or `online` in rLogin's configuration:

```yaml
auth-mode: auto   # Recommended — detects premium vs. non-premium automatically
# or
auth-mode: online # Forces all players to be treated as premium
```

<Note>
  If your `server.properties` has `online-mode=true`, your server already enforces Mojang authentication at the network level and only accepts premium players. rLogin's dual-authentication system is designed for servers running in **offline mode** that want to support both premium and non-premium players on the same server.
</Note>

## Benefits of Premium Authentication

  <Card title="Seamless Experience" icon="bolt">
    Premium players connect and play instantly — no registration, no password prompt, no extra steps at all.
  </Card>
  <Card title="No Password Management" icon="key">
    Premium players never create or manage a server-side password. Their Microsoft account is their credential.
  </Card>
  <Card title="Real Account Verification" icon="shield-check">
    Mojang's session API confirms each player's identity at every login, preventing username spoofing for premium accounts.
  </Card>

<Warning>
  Premium authentication requires your server to make outbound HTTPS requests to `sessionserver.mojang.com`. If your host's firewall blocks outbound connections, session verification will fail and premium players will be unable to log in. Contact your hosting provider to whitelist this endpoint if needed.
</Warning>
