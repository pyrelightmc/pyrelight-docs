This guide walks you through everything you need to get rLogin up and running on your Minecraft server. By the end, your server will automatically verify premium (Microsoft/Mojang) accounts through Mojang's session servers and prompt non-premium (cracked) players to register and log in with a password — all without any additional plugins.

## Prerequisites

Before you begin, make sure you have the following:

- A **Spigot, Paper, or Purpur** server running Minecraft **1.8 or later**
- **Java 8 or higher** installed on your server host
- Operator (`op`) or console access to run plugin commands

## Setup Steps

<Steps>
  <Step title="Download rLogin">
    Head to the [Pyrelight resource page](https://www.spigotmc.org) or the [GitHub releases page](https://github.com/rIgnacio/rLogin/releases) and download the latest `rLogin.jar` file. Always grab the newest release to ensure you have the latest bug fixes and security patches.
  </Step>

  <Step title="Place the JAR in your plugins folder">
    Copy `rLogin.jar` into the `/plugins/` directory at the root of your server installation.

    ```bash
    # Example on Linux
    cp rLogin.jar /path/to/your/server/plugins/
    ```
  </Step>

  <Step title="Start or restart your server">
    Start your server (or run `/restart` if it is already running). rLogin will boot up and automatically generate its default configuration files at `plugins/rLogin/`.

    Watch your console for a line similar to:

    ```
    [rLogin] Plugin enabled successfully.
    ```
  </Step>

  <Step title="Set your authentication mode">
    Open `plugins/rLogin/config.yml` in a text editor and set the `auth-mode` option to match your server's intended player base:

    ```yaml
    # plugins/rLogin/config.yml

    # auto    — mixed server: premium players are verified automatically,
    #           cracked players register and log in with a password
    # online  — only premium (Mojang-verified) players are accepted
    # offline — only non-premium (cracked) players are accepted
    auth-mode: auto
    ```

    For a mixed premium and cracked server, set `auth-mode` to `auto` and ensure `online-mode=false` is set in `server.properties` so the server accepts both account types at the network level.
  </Step>

  <Step title="Reload rLogin">
    Apply your configuration changes without a full server restart by running the reload command in-game or from the console:

    ```bash
    /rlogin reload
    ```

    Alternatively, do a full server restart to apply all changes cleanly.
  </Step>
</Steps>

<Tip>
  After completing setup, test your configuration by joining with both a legitimate premium account and a cracked/offline account. The premium account should pass through automatically, while the cracked account should be prompted to register or log in.
</Tip>

<Note>
  This guide covers only the essential steps to get rLogin running. For fine-grained control — such as login timeouts, session lengths, database backends, and custom messages — see the [Configuration](/configuration/config-file) documentation.
</Note>
